# Gridline Energy

A responsive marketing site for Gridline, an energy intelligence platform for energy-intensive operations.

## Live URL

grid-line-blond.vercel.app

## Local setup

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Tech stack

- Next.js App Router
- TypeScript
- Tailwind CSS v4 and custom CSS tokens
- Framer Motion reveal animations
- Lucide React icons

## Pages and actions

- Home: hero CTA, platform dashboard showcase, capabilities links, responsive navigation, and contact CTA.
- Platform: Monitor, Insights, and Control capability cards with contact links.
- About: company point of view, values, and contact CTA.
- Contact: validated name, email, and message form with success state.

## Design decisions

The visual system uses a warm paper background, deep green ink, acid-lime accent, mono utility labels, and editorial serif emphasis to combine industrial credibility with a clear, modern product feel. The homepage platform section uses a dashboard-style visual to make the product value concrete without relying on external assets.
